# Partnora — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Head of partnerships

- As a partnerships head, I want a pipeline of PB/fintech/BC/NGO opportunities scored on fit and regulatory risk, so that we stop signing decorative MoUs.
- As a partnerships head, I want KPI dashboards per live deal, so that underperforming partners face structured remediation or exit.
- As a partnerships head, I want coopetition conflicts visible before renewal, so that we do not fund our own disintermediation blindly.

### Payments bank product lead

- As a PB product lead, I want deposit-cap and non-lending constraints enforced in offer design with partners, so that we do not invent illegal products in a workshop.
- As a PB product lead, I want merchant and remittance performance by corridor, so that we invest in working last-mile nodes.

### Compliance / outsourcing officer

- As a compliance officer, I want launch gated on outsourcing and KYC checklists, so that speed does not create regulatory debt.
- As a compliance officer, I want data-purpose registers per partner, so that shared Aadhaar-linked attributes stay lawful.

### BC / inclusion network manager

- As a BC network manager, I want activation and dormancy metrics by agent and village cluster, so that inclusion claims are real.
- As a BC network manager, I want complaint ownership routing, so that customers are not bounced between bank and partner.

### Fintech relationship manager

- As a fintech RM, I want clear build-vs-integrate scopes and SLA clocks, so that bank procurement cycles are visible and manageable.
- As a fintech RM, I want a single evidence pack for security review, so that we do not resubmit the same artefacts quarterly from scratch.

### Finance partner

- As a finance partner, I want unit economics under PB float/fee constraints, so that “inclusion” deals that destroy value are redesigned or stopped.
